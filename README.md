# Thread Loop — NWA Closet Barter

A swipe-style clothing barter app for Northwest Arkansas. Browse local listings, list your own items, and match with neighbors to swap clothes — no cash needed.

## Features

- Swipe cards to **pass** or **swap** on local clothing listings
- Upload a photo and list your own item in seconds
- Match overlay + direct message when both parties want to swap
- Real listings powered by Supabase (falls back to demo cards offline)
- Flat-lay clothing cards — no model photos

## Live Site

[https://uncleb1981.github.io/Practice/](https://uncleb1981.github.io/Practice/)

## Stack

- Vanilla HTML / CSS / JavaScript
- [Supabase](https://supabase.com) for listings database
- Hosted via GitHub Pages

## Setup

1. Clone the repo
2. Open `index.html` in a browser — demo cards load automatically
3. To enable real listings, configure your Supabase project URL and anon key in `index.html`

## GitHub Pages

Go to **Settings → Pages**, set source branch to `main` (or the active branch), and the site will be live at the URL above.
